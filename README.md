# Triple Espresso — Cafetería de Especialidad

¡Bienvenido/a al proyecto! Esta es una página web interactiva desarrollada para la cafetería _Triple Espresso_ en Triple Peaks, creada como parte del Sprint 3 de TripleTen.

## Descripción del proyecto

El objetivo de este proyecto es ofrecer una plataforma moderna y fluida donde los clientes puedan conocer el menú, consultar la ubicación y horarios, reservar una mesa mediante un formulario interactivo y acceder a las redes sociales del establecimiento.

## ¿Qué encontrarás aquí?

- _Encabezado interactivo:_ Información clara sobre la marca, horarios de atención y dirección física.
- _Formulario de reservas:_ Un modal/sección interactivo para agendar mesas seleccionando número de comensales, fecha y datos de contacto.
- _Campos obligatorios:_ Validación integrada con asteriscos (\*) y atributos nativos de HTML.
- _Casilla de términos:_ Checkbox integrado para la aceptación de condiciones de uso.
- _Footer y redes sociales:_ Acceso directo a las redes oficiales con íconos vectoriales SVG y formas estilizadas.
- _Estados Hover:_ Transiciones suaves en botones, links de navegación y redes sociales para una mejor experiencia visual.

## Características técnicas

- _HTML5 Semántico:_ Estructura limpia y accesible para lectores de pantalla.
- _CSS3 Avanzado:_ Uso de propiedades modernas para posicionamiento y estilizado.
- _Metodología BEM:_ Clases organizadas bajo el esquema Bloque\_\_Elemento_Modificador para un código escalable.
- _Diseño Responsivo:_ Adaptación precisa mediante media queries para escritorio y dispositivos móviles.
- _Flexbox Layout:_ Alineación fluida de contenidos y cajas dentro del formulario y pie de página.

## ¿Cómo se hizo?

- Se construyó la estructura semántica base en HTML5.
- Se aplicaron estilos globales y normalize para unificar el renderizado entre navegadores.
- Se implementaron los formularios con validaciones y estilos personalizados en los inputs.
- Se diseñó el footer utilizando posicionamiento absoluto para figuras decorativas geométricas.
- Se añadieron micro-interacciones mediante la pseudoclase :hover con transiciones de color y opacidad.git
